## Como eu trabalho aqui

```
1. Reescrevo o problema com minhas palavras
2. Identifico o que entra e o que sai
3. Resolvo um exemplo no papel
4. Escrevo a solução burra (força bruta)
5. Só então penso em otimizar
```

O passo 4 é obrigatório. Solução feia que funciona vale mais que
solução elegante que não sai.

**Regra:** 20 a 30 minutos tentando de verdade antes de olhar
qualquer solução. Se olhar, fecho tudo e refaço do zero.
